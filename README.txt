DROPFlow — ЧИСТЫЙ V1 ДЛЯ GITHUB PAGES

ВАЖНО:
Этот index.html взят из проверенного DropFlow_V1_checked без добавления новых систем авторизации.

Авторизация:
- первый вход: пароль dropFlow-01-01;
- после успешного входа отметка хранится в localStorage этого браузера/устройства;
- при следующих открытиях пароль не запрашивается;
- выход через кнопку «Выйти» удаляет отметку авторизации и пароль снова понадобится.

ЧТО СДЕЛАТЬ В GITHUB:
1. Открой репозиторий DropFlow01.
2. Замени ТОЛЬКО существующий index.html этим index.html.
3. Если в репозитории ранее добавлялись sw.js и manifest.webmanifest специально для DropFlow, удали их — этот чистый V1 их не использует.
4. Не добавляй обратно IndexedDB/Cookie/Cache Storage/URL hash/другие системы авторизации.
5. Подожди, пока GitHub Pages обновится.

ВАЖНО ДЛЯ УСТРОЙСТВ, ГДЕ УЖЕ ОТКРЫВАЛАСЬ СТАРАЯ PWA-ВЕРСИЯ:
Если после замены страницы старый вариант всё ещё открывается или пароль ведёт себя неправильно, один раз очисти данные сайта DropFlow в браузере. Это нужно только для удаления старого service worker/кэша, если он был установлен предыдущей версией.

После очистки открой обычную ссылку GitHub Pages заново и введи пароль один раз.
